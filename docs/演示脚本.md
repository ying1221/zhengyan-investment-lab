## 自己录制的精简版口播

“这是证研，一个帮助研究者验证投资判断的产品。它不是先给结论，而是先把观点变成可验证命题。

例如，盈利改善主要来自主营业务。这里先明确公司和期间，再请用户确认‘主要’是过半还是超过七成。扣非利润只是代理指标，系统不会偷换为主营利润。

验证后，扣非增量贡献约五成七，达到过半阈值，但非经常差额增量也贡献了约四成三。我们同时展示支持、反对和无法验证的部分。点开任一证据，都能看到原始数值、计算和财报定位。

年度现金流好，与某一季度偏低可以同时成立。产品解释冲突，而不是用一段模糊总结抹平。缺少分部利润桥，就保留主营归因缺口。

把阈值提高到七成，同一证据不再达标。用户能看到结论改变的条件，再保存证据快照和待补问题。

最后，接口读取失败时停止输出数值判断；模型没有实际调用就标明规则模式。本原型使用公开历史财报，授权数据与模型的进一步联调如实列入未完成事项。”

## 可复现生成方式

本地 `npm run dev` 后，另开终端：

1. 安装浏览器：`npx playwright install chromium --only-shell`；录屏依赖：`npx playwright install ffmpeg`。
2. Windows 本机旁白：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/narrate.ps1`。
3. 音轨准备：`python scripts/video-audio.py`。
4. 实际操作录屏：`node scripts/record-demo.mjs`。
5. 安装合成工具：`python -m pip install imageio-ffmpeg`；合成：`python scripts/video-audio.py --merge`。

生成工具与浏览器操作脚本是开发辅助，不属于产品运行依赖。演示字幕由录制脚本叠加，不是运行时模型输出。个人重录可直接用系统录屏，无需这些工具。
