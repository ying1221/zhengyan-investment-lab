# 模型连接排查

2026-10-22 更新：用户实测出现模型降级，截图不足以确定原始根因。本次修正了请求预算与错误可见性；未宣称已用用户真实密钥复测成功。

## 本次修正

- DeepSeek 官方文档说明当前模型默认启用思考模式。本产品只需要基于有限证据生成简短解释，因此明确设置 `thinking.type=disabled`，避免推理占用输出预算。
- 后端等待上限由 25 秒调整为 45 秒，前端为 60 秒；不在后台静默多次重试收费调用。
- 区分 HTTP 401、402、422、429、服务不可用、网络失败、超时、空正文、输出截断、JSON 格式、结构与引用错误。
- 修正关键词检查对“不提供仓位建议”“不保证收益”的误拦；仍不接受实际交易建议与收益承诺。该规则是原型护栏，不等于完整合规审查。
- 在结论下方显示错误码、HTTP 状态、阶段、耗时、结束原因与正文长度；不回传密钥或提供商原始错误正文。
- 保留规则结论，提供手动重试与导出诊断记录。

依据：[官方思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)、[官方错误码说明](https://api-docs.deepseek.com/quick_start/error_codes/)、[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。

## 页面错误码

| 错误码 | 含义与处理 |
|---|---|
| AUTH_FAILED / HTTP 401 | 核对是否为有效的 DeepSeek 平台密钥 |
| INSUFFICIENT_BALANCE / HTTP 402 | 在 DeepSeek 官方平台核对账户额度 |
| REQUEST_REJECTED / HTTP 400 或 422 | 请求或参数需要修正，导出诊断记录供开发排查 |
| RATE_LIMIT / HTTP 429 | 请求频率或并发受限，稍后手动重试 |
| MODEL_TIMEOUT | 超过等待上限，稍后手动重试 |
| NETWORK_ERROR / PROVIDER_UNAVAILABLE | 网络或提供商暂不可用 |
| OUTPUT_TRUNCATED / EMPTY_OUTPUT | 没有获得完整可用正文 |
| JSON_INVALID / SCHEMA_INVALID | 输出格式或结构未通过约定 |
| CITATION_INVALID | 引用缺失、未知或不一致，不能放宽为成功 |
| COMPLIANCE_REJECTED | 输出命中交易或收益承诺检查，需人工复核 |

## 用户操作

打开 `/?settings=1` → 输入密钥 → 勾选模型辅助 → 正常模式 → 应用设置 → 拆解命题 → 确认口径，开始验证。

成功时，结论下方显示“DeepSeek 调用成功”，下方出现模型辅助解释。失败时直接查看结论下方诊断卡，或导出诊断记录。密钥只在当前页面内存，刷新后需要重新填写。
