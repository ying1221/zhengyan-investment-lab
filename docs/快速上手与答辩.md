# 5 分钟理解产品

一句话：证研把投资直觉变成可检验命题，强制检查反证与缺口，并把结论挂回原始披露。

## 先自己点一遍（约 2 分钟）

1. 默认命题 → **拆解命题**。看见公司、期间、贡献阈值与四个子问题。
2. 保留 **50% 过半** → **确认口径，开始验证**。
3. 看到归母同比 **14.29%**、扣非增量贡献 **57.43%**、经营现金覆盖 **1.57 倍**。结论只对修订命题有条件支持，仍保留主营归因缺口。
4. 切换 **反对 / 限制** → 点开 E4。看公式，再打开原始 PDF 第 4 页。
5. **继续比较** → **用 70% 阈值重新验证**。结果变成未通过阈值；变化来自命题强度，不是系统随意改口。
6. **保存为研究任务** → 左侧研究任务。未验证问题与反转条件会一起保存。
7. 设置 → 财报读取超时 → 应用 → 修订命题后重验。系统不再展示数值结论。完成后恢复正常模式。

## 你需要真正理解的三个数字

归母利润增量：`38,537,237 − 33,719,935 = 4,817,302 千元`。

扣非利润增量：`35,741,418 − 32,974,908 = 2,766,510 千元`。

扣非增量贡献：`2,766,510 / 4,817,302 = 57.43%`。剩余 **42.57%** 是归母与扣非差额增加的贡献。

这能说明经常性盈利增量贡献过半，却不能直接证明主营驱动，因为扣非不等于主营、财报代理指标不等于因果识别。

## 面试追问，怎么回答

**为什么不是普通财报问答？** 输出单位是可修订命题与证据链，包含阈值、反证、未知、反转条件和后续任务，不只生成一段解释。

**为什么用规则，而不是全交给模型？** 财务计算与来源定位需要可重复；模型适合语义理解和辅助解释。两者分工，让模型失败不破坏事实层。

**真的调用 AI 了吗？** 已有真实 DeepSeek 调用，用户提供截图、JSON 和报告，耗时 1,955 ms，本次数字与引用语义已核对。免密钥案例展示的是带时间的历史归档；新的实时调用仍需要访问者配置密钥。开发辅助、规则计算、实时模型和历史记录分别标记。

**多证据为什么只有一个来源组？** 多个财务维度和时间粒度构成多条证据，但同一份披露不是独立印证。我选择如实标记，而不是把镜像、摘要与全文算成三个来源。

**为什么“支持”和“反对”能同时存在？** 每条证据针对具体子问题。扣非增量贡献过半支持弱命题，非经常性贡献不可忽略限制“全部来自主营”的强命题；年度与季度也可以表现不同。

**57.43% 是模型算的吗？** 不是，代码从原始千元数据复算，并展示公式。模型不能修改数值判定。

**为什么不用最新财报？** 这是明确时间锚点的历史回溯案例，避免混用口径与实时数据假象。拿到授权后优先做按披露时间更新与版本保留。

**怎样避免幻觉？** 有限证据包、明确缺失、引用 ID 与结构校验、数字规则计算、展示原文入口和模型状态。语义蕴含校验尚未完成，不能声称彻底解决幻觉。

**怎么验证产品有效？** 先用黄金案例检验数据与异常，再用目标用户验证能否更快发现薄弱环节。当前工程测试通过不代表产品价值已获得用户验证。

**正式上线还差什么？** 真实授权数据与模型联调、广泛测试集、权限隔离、速率限制、持久化、安全与合规评审。当前是可运行原型，非正式投顾服务。
