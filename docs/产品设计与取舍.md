# 证研：用证据检验判断

## 1. 产品定位

面向有明确投资观点、需要核实论据的个人研究者与初级投研人员。核心任务不是得到一句“看好 / 不看好”，而是在 3 分钟内知道：命题具体是什么、哪些材料支持、哪些反对、哪里仍然不知道，以及下一步补什么证据。

本次以美的集团 2024 年报做纵向打通的可运行 MVP；没有授权的扶摇 / iFinD 不做假接入。数据期间固定，不把 2024 年事实当作当前投资建议。

## 2. 核心用户故事

“我看到利润增长，怀疑主要来自主营。希望有人先帮我把‘主要’说明白，再帮我找反证，最后告诉我这个判断还缺什么。”

当前替代流程是找年报、抄数字、询问通用聊天模型、来回核对来源。主要痛点：观点模糊、确认偏误、会计口径混用、模型编造引用、结论不能被复查。

## 3. 关键设计

1. **确认后再验证**：先明确对象、时间与贡献阈值。默认 50% 是研究约定，可改为 70% / 100%，不将其包装成公认标准。
2. **拆解而不偷换**：把“主营驱动”拆成盈利增长、经常性增量贡献、现金支撑、业务归因四个问题。明确扣非只是代理，保留主营归因缺口。
3. **支持、反对、未知同屏**：未知不等于反对；反对证据说明具体针对的是原命题还是更强的延伸判断。
4. **不输出伪精确置信度**：不做“可信度 92%”。直接展示覆盖范围、同源组数、规则阈值与缺失材料。
5. **冲突分类处理**：先检查同公司、同期、单位、会计准则、年度 / 季度粒度，再判断是真冲突还是可以并存。全年现金流好与 Q4 偏低可以同时成立。
6. **不按条数投票**：同一发行人的年报摘要和全文归并为一个来源组。多个指标是多条证据，不等于多个独立来源。
7. **显式反转条件**：新增 / 重述数据低于贡献阈值、分部利润桥不支持主营归因、可比季度现金转换持续恶化，均触发重新研究。
8. **结论进入工作流**：追问、阈值 / 期间比较、保存带证据快照的任务、导出报告。保存为浏览器本地任务，不暗示后台持续监控。

## 4. AI 与规则的分工

确定性层：研究范围校验、模板拆解、披露快照读取、财务计算、证据 ID、阈值判断、同源去重、异常降级。这样每个数字都可复算。

可选大模型层：以受限证据包辅助解释与提出后续问题，支持自由追问。模型只接收命题与必要的证据字段；不让模型生成财务原始数值、决定阈值判定或伪造来源。

模型结果必须通过 JSON 结构、已知引用 ID、引用与正文一致性、部分交易话术检查。校验失败保留规则结果。**引用存在不代表解释正确**，尚需人工核查语义、数字一致性与金融边界；当前不是经监管评估的投顾系统。

当前未提供有效模型密钥，因此没有宣称完成真实模型联调。自动化测试中的模型成功 / 401 / 429 / 错误引用均使用网络替身，并在测试记录中标明。

## 5. 状态流

输入 → 范围校验 → 修订与澄清 → 用户确认 → 加载证据包 → 财务复算 → 支持 / 反对 / 缺口 → 有条件支持 / 未达阈值 / 证据不足 → 追问或保存。

范围不符：停止，不给样本结论。财报读取超时：无数值指标，证据不足。模型失败：模型状态明确失败，规则结果保留。买卖 / 收益承诺问题：回到研究边界。

## 6. 数据结构

证据包含 `id / stance / question / fact / reading / formula / source / group / locator / strength`；事实、解释和缺口分开。研究结果记录原命题、修订命题、阈值、规则状态、模型调用状态、runId、生成时间和数据披露日期。保存任务时保留快照，未来数据变化不会覆盖过去判断。

数据：原始单位人民币千元，展示亿元时除以 100,000；同比增长与百分点区别处理；不存在的数据不补 0；年度与单季不混用；无行情数据则不计算 PE。

## 7. 评估指标（拟议，非已观测结果）

首要指标：用户确认后，完成一条可追溯验证链的比例。质量护栏：数值复算一致率、有效来源定位率、缺口明确率、同源误算率、被注入指令影响率、异常时错误输出肯定结论的比例。

实际只有工程测试，没有进行用户研究或宣称线上效果。后续可请 5–8 位目标用户完成默认命题与陌生命题任务，测完成时间、口径修订率与来源核查成功率。

## 8. 边界与后续

当前只覆盖一家公司的一个报告期和三类模板；不支持任意公司、任意年份、跨市场可比估值、全文自动检索、研报授权数据或因果归因自动证明。反向 / 否定命题会要求改写，防止静默反转。

短期优先：获得授权数据接口 → 可插拔适配器与真实错误码测试 → 多公司 / 多期间 → 分部利润桥与非经常明细 → 实测模型语义引用与注入攻击 → 云端任务持久化。后台监控、提醒、登录协作应在授权与存储能力明确后再做。

不做事项：交易执行、投资组合建议、收益预测或承诺、绕过账号与数据版权、未经用户确认的外部消息通知。
